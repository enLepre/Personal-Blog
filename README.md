# Personal Blog

A minimal personal academic website for research, notes and essays.

## Structure

- `index.html` — minimal landing page
- `research.html` — research and publications
- `notes.html` — digital garden
- `essays.html` — long-form writing
- `about.html` — biography, CV and contact
- `styles.css` — shared visual design
- `assets/landscape.svg` — homepage illustration

The site is intentionally static and dependency-free, so it can be hosted directly with GitHub Pages.

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
